01. EXECUTIVE_ARCHITECTURE_OVERVIEW

Landscape Vault is an archival procedural generation engine synthesizing Chinese classical landscape painting (Shan Shui / 山水画) scrolls, album leaves, and architectural plates. It is adapted from Lingdong Huang's seminal engine shan-shui-inf (2018) and re-engineered according to the Swiss-Archival design system of Azzar Budiyanto.

The engine outputs 100% deterministic vector SVG documents that incorporate layered rock facets, mountain pines, pagodas, bridges, river ripples, flying cranes, Swiss-Archival dual drafting borders, a Topographical Survey Scale Bar (10 Li / 5 Km Rule), a Cinnabar Vermilion Seal Chop (朱砂印章 · 山水典藏), and an engraved Hershey cursive vector Latin title.

02. PROCEDURAL_SYNTHESIS_PIPELINE

The synthesis engine operates through five sequential phases:

  1. Narrative Seed Hashing: Computes a 32-bit FNV-1a hash from the narrative string to seed the isolated PRNG and Perlin Noise engines deterministically.
  2. Topographical Planning: Samples noise octaves across the horizontal axis to determine peak locations, ridge heights, and valley depressions. Distant peaks and crane flocks are deployed in the upper third of the canvas.
  3. Vector Linework & Texture Synthesis: Executes Lingdong Huang's stroke algorithms, generating layered rock fractures (Mount.mountain), flat islands (Mount.flatMount), architectural structures (Arch.arch01-04), boats (Arch.boat01), and river ripples (water).
  4. Depth-Sorted Occlusion: Organizes visual chunks in painter's depth order along the vertical axis (y), utilizing white occlusion polygons that blend cleanly into the Xuan paper plate via mix-blend-mode: multiply.
  5. Archival Framing & Calligraphy: Injects drafting borders, metric survey rule, cinnabar seal chop, and Hershey vector cursive calligraphy into the final SVG plate.

03. JAVASCRIPT_API_REFERENCE

Landscape Vault exposes a zero-dependency UMD module via window.LandscapeDraw:

LandscapeDraw.synthesize(seedInput, options)

Synthesizes a procedural landscape specimen and returns all telemetry, SVG elements, and dimensions.

const specimen = LandscapeDraw.synthesize("Misty Mountain Peaks in Late Autumn Solitude", {
  width: 1200,
  height: 800,
  pigment: "pine-soot" // "pine-soot" | "shallow-umber" | "blue-green" | "golden-dusk" | "mist-ink"
});

console.log(specimen.id); // e.g. "LSV-0B-B2493C"
console.log(specimen.metrics.title); // e.g. "Nebulae Super Valles"
console.log(specimen.metrics.zhTitle); // e.g. "万壑云烟图"

LandscapeDraw.generateSvgPlate(data, options)

Generates a complete standalone SVG document complete with archival borders, survey scale rule, and vermilion seal chop.

const svgString = LandscapeDraw.generateSvgPlate(specimen);
// Save to file or inject into DOM

LandscapeDraw.renderToCanvas(data, canvas, options)

Renders the specimen onto an HTML5 canvas at any target resolution for high-resolution 300 DPI PNG export.

const canvas = document.createElement('canvas');
canvas.width = 2400;
canvas.height = 1600;
await LandscapeDraw.renderToCanvas(specimen, canvas);
const pngDataUrl = canvas.toDataURL('image/png');

04. EMBED_INTEGRATION_PROTOCOL

Add mode=embed to any Landscape Vault URL to enable distraction-free specimen rendering optimized for iframes: 

<iframe 
  src="https://landscape-vault.glassgallery.my.id/?id=LSV-0B-B2493C&pigment=pine-soot&w=3&h=2&mode=embed" 
  width="100%" 
  height="600" 
  frameborder="0" 
  style="border:1px solid #DDD5C5; background:#EFE9DC;">
</iframe>

Dynamic postMessage Controller

// Send new landscape parameters to embedded iframe
const iframe = document.querySelector('iframe');
iframe.contentWindow.postMessage({
  seed: "Solitary Fishing Boat on Cold River at Dusk",
  pigment: "blue-green",
  w: 16,
  h: 9
}, "*");
